# paper-collage-explainer-v1

使用此风格制作 9:16 的原创编辑型纸拼贴知识讲解视频。它不是 V2 的替代品：V2 保持 3:4 双语出版物模板；本风格以“一个口播概念 + 一个视觉隐喻 + 一条短 B-roll”为基本单元。

## 选择与产物

| 适用情况 | 选择 |
| --- | --- |
| 需要稳定的书封、双语字幕、3:4 交付 | `book-editorial-bilingual-v2` |
| 需要 9:16、高信息密度、纸拼贴隐喻和短视频节奏 | `paper-collage-explainer-v1` |

使用 `config/style_profiles/paper-collage-explainer-v1.json` 作为机器可读的制作约束。每次生成必须创建新的 `release_id`，例如 `collage-v1-r1`；禁止覆盖已批准母版。

## 生成渠道

### Gemini API：自动化渠道

仅在用户授权付费生成与提供 `GEMINI_API_KEY` 后使用。不要把密钥写入项目文件、日志、manifest 或提示词。

- 使用 Gemini Omni Flash 作为默认短视频生成/编辑模型。
- 需要首尾帧插值、参考图或 Veo 视频延长时，使用 Veo 3.1。
- 每次请求固定记录：模型、提交时间、operation/job ID、完整提示词、输入资产 SHA-256、输出 SHA-256、暴露的用量/费用和失败原因。
- 每条 B-roll 维持 9:16、4–8 秒；Google 当前 API 文档支持 4/6/8 秒档，实际可用模型、配额、区域和价格必须在运行前复核。
- 若模型生成原生音频，默认在本地渲染阶段静音；项目授权旁白、BGM 与 SFX 才是成片音轨真值。

官方依据：<https://ai.google.dev/gemini-api/docs/video> 与 <https://ai.google.dev/gemini-api/docs/veo>。

### Google Flow：手工创作渠道

Flow 是 Google 的创作工作台，不是此技能可假设调用的 API。它适合导演逐条尝试画面与镜头感；自动化批量生产优先使用 Gemini API。

- 前提：用户自己的合格 Google AI 订阅、可用 credits、桌面 Chromium 浏览器和用户允许的账号会话。
- 不读取或绕过账号、credits、下载限制或浏览器登录。
- 每条导入片段保存 Flow prompt、输出日期、可见 credits、导出文件、SHA-256 和对应 `scene_id`。
- 仅导入已由用户合法导出的文件；不要把 Flow 的 UI 预览当成可发布资产。

官方依据：<https://labs.google/fx/tools/flow/faq>。

## 核心工作流

1. **资料与脚本**：先锁定资料包与短脚本。每一行口播只表达一个概念，不把读者评论写成事实；英文稿持续标为 `needs_native_review`。
2. **Gate 1 — 隐喻**：为每个 4–8 秒单元写一行：`概念 → 可见物体/关系 → 动画动作 → 禁止项`。例如“健康寿命 → 明亮时间线覆盖灰色纸层 → 撕开纸层露出路径 → 不出现医疗承诺”。
3. **Gate 2 — 静帧/联系表**：先审第一帧、尾帧或联系表，检查画面中心、安全区、纸材质、文字污染、重复隐喻与水印。未通过不得生成完整片段。
4. **Gate 3 — 生成与 QA**：通过 Gemini API 或 Flow 生成短 B-roll；保留原始输出、来源记录和成本事件。检查时长、9:16、可解码、无可读水印、无嵌入字幕、无明显尾帧漂移。
5. **规范化**：将批准片段转为项目内无音频 H.264 MP4；使用 `S01`…`S12` 或脚本行 ID 命名。不要用生成片段的原生音轨。
6. **本地时间线**：以锁定旁白和 ASR 时间为真值，映射每个 B-roll；本地渲染字幕、真实书封、品牌层、原创/已授权 BGM 和 SFX。
7. **音频与技术 QC**：BGM 需要权利/来源证明；人声需授权；检测完整解码、帧率、画布、音画时长、响度、真峰值、黑帧和水印。
8. **人工审批与交付**：用 `workflow.py approve` 将审片、BGM 审听和本地母版决定绑定到输出哈希。发布权、书封权、英文母语审校和来源审计仍须单独通过。

## 提示词骨架

每条短 B-roll 只描述一个可见动作。保留以下字段，避免把整篇口播塞进单条视频提示词：

```text
场景目的：<该口播行让观众理解的唯一关系>
视觉隐喻：<纸片/人物/路径/图表/物件之间的可见关系>
构图：9:16，主体在中央安全区，<前景>/<中景>/<背景> 分层。
材质：原创编辑型纸拼贴，撕纸边缘、档案纹理、有限配色、清晰留白。
动作：<一个主动作>；镜头仅<轻推近/轻平移/分层视差>。
避免：任何品牌或节目模仿、logo、水印、可读文字、书封复刻、快速旋转、强闪烁、复杂人物对白。
音频：静音输出；成片音频后期统一添加。
```

## 最低 manifest 字段

每个生成片段的资产记录至少包含：`release_id`、`scene_id`、`script_line_id`、`provider_lane`、`model_or_flow`、`prompt`、`input_hashes`、`output_path`、`output_sha256`、`duration_seconds`、`ratio`、`audio_policy`、`gate_1`、`gate_2`、`gate_3`、`reviewer`、`cost_evidence`。

没有这些字段，不得把片段视为可复用或可交付资产。
