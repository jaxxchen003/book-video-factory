## 可复刻的结构

1. 0–2 秒以一句强情绪钩子进入，不先解释背景。
2. 黑色大留白配低饱和人物肖像，主体通常偏左或偏下。
3. 中文主字幕位于画面中央到下半区，字号大、每屏字少，跟随旁白逐句替换。
4. 英文副字幕可选，只做氛围辅助，不承担信息完整性。
5. 书名、作者和封面作为背书镜头出现；底部账号标识保持固定。
6. 全片约 10–14 个画面单元，平均每 3–5 秒变化一次，以淡入淡出和轻微推拉为主。
7. 画面文字必须由渲染层生成，禁止让图片模型直接绘制中文。

## 首版模板参数

- 输出主规格：720×960；同时保留 1080×1440 高清档。
- 安全区：左右各 54 px，顶部 72 px，底部 105 px（720×960 基准）。
- 背景亮度低、饱和度低；人物与关键物件允许一个暖色视觉锚点。
- 单条旁白目标 45–60 秒；句子短，停顿明确，字幕每屏建议 6–16 个汉字。
- 人声是信息主轨，BGM 只提供情绪并在旁白期间自动 ducking。
